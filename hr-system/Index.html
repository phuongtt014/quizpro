⬆️ Import Nhân Sự CSV

Upload file CSV theo template. Mã NV đã tồn tại → cập nhật. Mã NV mới → thêm mới.

📄

Kéo thả CSV hoặc nhấn để chọn

UTF-8 · .csv

⬇️ Xuất & Template

Xuất danh sách hoặc tải mẫu CSV với đầy đủ quy định từng trường.

📌 Quy tắc Import Nhân Sự

• ✱ Bắt buộc: Mã Nhân Viên, Họ Tên — thiếu 1 trong 2 → dòng bị bỏ qua
• Mã NV đã tồn tại → cập nhật thông tin. Mã NV mới → thêm mới
• Trường dropdown phải nhập đúng giá trị có sẵn — sai → dòng bị bỏ qua hoàn toàn
• Các trường Chức Vụ Chính, Chức Vụ Kiêm Nhiệm, Đơn Vị Phòng được tự động cập nhật từ Hợp Đồng — không cần nhập
• Ngày theo định dạng dd/mm/yyyy · File CSV mã hoá UTF-8

⚙️ Import Cấu Hình Danh Mục

Upload CSV dạng danh sách — mỗi dòng là 1 giá trị. Hệ thống sẽ thêm vào danh sách hiện có.

⚙️

Kéo thả CSV cấu hình hoặc nhấn để chọn

⬇️ Template Cấu Hình

File mẫu với cấu trúc đúng và dữ liệu ví dụ.

📌 Cấu trúc file CSV Cấu Hình

File có 3 cột:
• KEY — mã danh mục (VD: donVi)
• LABEL — tên hiển thị (VD: Đơn Vị)
• VALUE — 1 giá trị mỗi dòng

Ví dụ:
donVi,Đơn Vị,Tổ Toán
donVi,Đơn Vị,Tổ Văn
→ Mỗi dòng = 1 giá trị riêng biệt.

📄 Import Hợp Đồng / Phụ Lục CSV

Upload file CSV. Nếu trùng Số HĐ/Phụ Lục của cùng nhân sự → chỉ cập nhật thay đổi mới. Chưa có → thêm mới.

📄

Kéo thả CSV Hợp Đồng hoặc nhấn để chọn

UTF-8 · .csv

🔄 Cập Nhật Hồ Sơ Theo Hợp Đồng

Import hợp đồng không tự động đổi Đơn Vị Phòng / Chức Vụ trong hồ sơ. Nhấn nút bên dưới để đồng bộ hàng loạt từ hợp đồng đang hiệu lực (tại hôm nay) về hồ sơ nhân sự. Hệ thống sẽ hiện danh sách thay đổi để bạn xác nhận trước khi ghi.

⬇️ Template & Quy Định

Tải file mẫu kèm bảng quy định chi tiết các trường.

📌 Quy tắc Import Hợp Đồng

• * Trường bắt buộc: MaNV, Số HĐ/Phụ Lục, Loại HĐ/PL, Ngày Ký, Ngày Hiệu Lực — thiếu 1 trong các trường này → dòng bị bỏ qua
• Nếu Số HĐ/Phụ Lục trùng (cùng nhân sự) → chỉ ghi nhận thay đổi mới, giữ nguyên thông tin cũ
• Chưa có Số HĐ → tạo mới bản ghi hợp đồng
• Ngày theo định dạng dd/mm/yyyy · Số tiền chỉ gõ chữ số
• Hệ thống chỉ import dòng nào cung cấp đủ tất cả trường bắt buộc

🎓 Import Phát Triển Bản Thân CSV

Upload file CSV để import hàng loạt bằng cấp, chứng chỉ. Mỗi dòng = 1 bằng cấp của 1 nhân sự.

🎓

Kéo thả CSV Phát Triển hoặc nhấn để chọn

UTF-8 · .csv

⬇️ Template & Quy Định

Tải file mẫu kèm bảng quy định chi tiết các trường.

📌 Quy tắc Import Phát Triển Bản Thân

• * Trường bắt buộc: MaNV, Loại Bằng/Chứng Chỉ, Tên Bằng/Chứng Chỉ — thiếu 1 → dòng bị bỏ qua
• Mỗi dòng = 1 bằng cấp / chứng chỉ riêng biệt
• Ngày theo định dạng dd/mm/yyyy
• Hệ thống chỉ import dòng nào cung cấp đủ tất cả trường bắt buộc
