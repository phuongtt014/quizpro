Chẩn đoán dữ liệu

Dùng khi nghi ngờ 1 tab không thấy dữ liệu mới. Bấm "1. Ping" trước để chắc chắn kết nối client-server hoạt động bình thường (hàm này không đụng tới Sheet), rồi bấm "2. Kiểm tra dữ liệu" để xem chính xác server đang đọc được gì từ sheet HoSo/CongViec ngay lúc này. Nếu kết quả hiện ra chữ null hoặc "LỖI", hãy mở Apps Script → mục Thực thi (Executions) để xem log lỗi chi tiết, hoặc nhấn F12 trên trình duyệt → tab Console để xem lỗi JavaScript.

Nút 3 ghi thử 1 dòng đánh dấu rồi đọc lại ngay ở 1 lượt gọi server hoàn toàn khác (mô phỏng đúng tình huống ghi hồ sơ rồi chuyển tab khác xem ngay) — nếu báo "KHÔNG thấy" thì bản DB.gs đang chạy chưa có bản vá mới nhất, cần dán lại đúng nội dung file này rồi deploy lại.
